# 临床秘书 使用说明（v1.0）

## 一、装 APK

把 `临床秘书-v1.0.apk` 传到手机安装。首次安装需要允许"安装未知来源应用"。

装好后桌面出现「小满」。不要开无障碍服务——这个版本不需要。

## 二、填 Key（只填一处）

打开「设置」：

| 项 | 填什么 |
|---|---|
| 聊天模型 Base URL | 已默认 `https://api.deepseek.com/v1` |
| 聊天模型名称 | 已默认 `deepseek-flash`（**不是** `deepseek-v4.1-flash`，API 不认那个名字） |
| 聊天模型 API Key | 你的 DeepSeek Key（`sk-` 开头） |
| Temperature | 留空即 0.2，别填 1.0 |
| 操作模型 | **全部留空** |

DeepSeek Key 在 https://platform.deepseek.com/api_keys 申请。充值 10 元能用很久：
每条消息约 1-3 分钱，一天说 50 句大概几毛钱。

## 二之二、填完先点「测试连接」

聊天模型下面有个**测试连接**按钮（v0.5 起）。它会用你当前填的三个框发一句「你好」出去，把模型的原话回给你：

- 通了：`连接正常：你好！有什么可以帮你…`
- 不通：直接显示服务商的原话，比如 `HTTP 400 ... Model Not Exist`

这一步不用保存、不用回聊天页，改完再点一次就行。**报错先点它**，比在聊天里试快得多。

常见报错对照：

| 报错里出现 | 真正的问题 | 怎么改 |
|---|---|---|
| `Model Not Exist` / `model_not_found` | 模型名写错 | 填 `deepseek-flash`。注意 `deepseek-v4.1-flash` 是模型宣传名，API 不认；`deepseek-chat`、`deepseek-v4-flash` 是兼容别名 |
| `Authentication` / `invalid api key` | Key 错、被删、或复制多了空格 | 重新复制 `sk-` 开头那一整串 |
| `Insufficient Balance` | 余额不够 | 充值 |
| `does not support tools` | 这个模型不支持函数调用 | 换一个支持 tools 的模型（待办全靠工具，不支持就用不了） |
| `Connection` / `timeout` | 网络 | 换 Wi-Fi 或关代理 |

聊天里的错误提示也改了：400/401/403/404 这类**重试没用的**错误，现在会明说「配置问题，重试无效」，并把服务商原话括号在后面。

## 二之三、深度思考默认是关的

v0.6 起，每次请求都带 `thinking: disabled`。三个原因：

1. DeepSeek 开着思考时，一句话要等十几秒才回，你站在病房里等不起
2. 思考的 token 也计费，一天说 50 句能省一半钱
3. **开着思考时 temperature 直接失效**，你填 0.2 没用

代价是遇到特别绕的事（比如一张表 40 行、姓名又有重名）它可能不如开着想得周全。真需要，跟我说，我加个开关。

**不要把 Key 发给我，也不要贴进任何聊天窗口**，只填在手机设置里。

## 三、允许通知

Android 13 以上第一次打开会问通知权限，选允许。这个必须给，否则四个时点不会弹。

## 四、试这几句话

```
新入 12 床李xx，胆囊结石，待手术
给 12、11 床换药
1、5、10 床出院
12 床请了心内科会诊
明天给 12 床查血
12 床提了用药申请
今天还有什么待办
```

助手会复述一行给你确认，你回「对」才写入。

再试这几句：

```
12 床排手术了
12 床调到 15 床
12 床看过了
12 床会诊回了
每月 10、20、30 提醒我上报药物不良反应
这个月报了
```

## 五、什么时候会响

每天 **08:00 / 11:00 / 14:00 / 17:00**，一条聚合通知，列出所有该关注的事。

- 你没回应 → 下一个时点继续响
- 你说「看过了」→ 当天不再响，次日恢复
- 你说「办完了 / 排手术了 / 会诊回了」→ 关闭，不再响
- 超过有效期 → 不再响，但在「今天还有什么待办」里单列为「已过期未确认」

## 五之二、长按标题，立刻试一次推送

不想等到明早 8 点才知道通不通，就**长按顶部「小满」两个字**。

它会按"现在就是时点"算一次，把今天该关注的推成一条通知，弹完提示「已推送 N 条」。没有到点的事项也会发一条测试卡片，正文写着「能看到这条，说明通知通道是通的」。

长按是测试入口，不累计推送次数、不影响第二天的正常提醒。正常用的时候完全碰不到它。

如果提示「通知被系统拦了」，去设置里允许通知，再长按一次。

## 六、数据存在哪

```
/sdcard/Android/data/dev.xiaoman.app/files/tasks/tasks.json     活跃待办
/sdcard/Android/data/dev.xiaoman.app/files/tasks/archive/*.md   归档（每月）
```

- 重启手机不会丢，开机后自动重排提醒
- 卸载 App 会一起删掉，重要数据先拷出来
- 归档是纯 Markdown，可以直接看
- 每月第一次打开时，自动把上上个月及更早的已关闭事项挪进归档

## 七、语音输入

直接用输入法的麦克风键说话，说完转成文字进输入框，和打字一样处理。

助手听得懂「十二床」这种中文数字，会自动转成 12。

## 八、姓名对不上时

助手会停下来问：

> 12 床登记的是李xx，你刚才说的是黎xx，是同一个人吗？

回「是」才写入；回「不是」它会当成新患者。这样调床和同音字都不会串人。

## 九、出问题时

- 通知不响：检查通知权限、检查电池优化是否把小满限制了（设置 → 应用 → 小满 → 电池 → 不限制）
- 回复"待办功能没有启用"：说明 APK 装的是原版小满，不是改造版
- 想清空重来：删掉 `tasks/tasks.json` 即可

## 十、发照片

输入框左边多了个图片按钮，点开是系统的相册/照片选择器（v0.3 起）。

选好之后会先弹一张预览，加一句话：

> 发之前看一眼：图里不要出现患者姓名、住院号、身份证号，也不要拍检查报告单的抬头。

你点「确认发送」才真的发出去。这句话不是客套，照片是**整包发到 DeepSeek 云端**的，图里有什么模型就看见什么，收不回来。

**可以拍的**：自己手写的待办清单、排班表、白板上的床号顺序、书本或文献里的一段。
**不要拍的**：病历夹、化验单、检查报告、带姓名的床头卡、手术同意书。

拍手写清单最省事：写完一排，拍一张，说「记一下」或者什么都不说直接发，助手会拆成一条条待办，再复述让你确认。**床号看不清要问它，它会问你，别让它猜。**

两个实现细节：

- 照片在手机里先压到长边 1024、JPEG 85，一般 150–400 KB 再发，不会卡着转圈。
- 图片只在这一轮对话里出现，之后的对话历史里只有一行「（附图 1 张）」的备注，不会再重复上传、也不再重复计费。

如果发图报错（比如模型不支持图片），把设置里的模型名换成控制台里确切的多模态型号。

## 十一、查房前核对床号（HIS 表照片）

v0.4 新加的一条：查房前把 HIS 病房表拍一张发过去，说「核对一下」，它拿表上的床号+姓名和你记着的待办比一遍，专治调床之后床号对不上。

它只做三件事：

| 情况 | 它怎么做 |
|---|---|
| 同一个人换了床 | 直接改成新床号，回你「12床 李xx → 15床，已改」 |
| 同一张床换了别人 | 不动，问你：`8床 待办记的是 李xx，HIS 是 王xx`，你决定怎么处理 |
| 表里找不到这个人 | 不动，问是否已出院或转走，你说出院了它再关 |

最后给你一行总数：`核对 12 人：改床 2，待你定 1，查无 1`。

几个要点：

- **只读两列**：床号、姓名。诊断、住院号、检查结果它不读也不记。
- 姓名被 HIS 打成 `李**` 也能对上，按看得见的前缀匹配；但两个人都叫 `李**` 时它会说「同名多人，认不出」，让你自己定。
- 表格拍不清就直说，不猜床号。猜错比不猜更糟。
- 想先看再改，说「只核对，别改」，它只报告不动手。
- ⚠️ **这张图和你手写清单不一样**：核对床号必须带姓名，也就是说**姓名一定会随图上云**。这跟「发照片」那句脱敏提醒是冲突的，你自己权衡。要是这条红线不能碰，就别用这个功能，继续口报床号。

## 十二、开机自启与后台

**不需要常驻后台。** 提醒不靠 App 一直活着，靠的是系统闹钟：到点由系统唤醒小满的接收器，弹完通知就结束。App 进程被回收也不影响，反而更省电。

**开机自启已经做了**：手机重启或覆盖安装后，小满会自动把 08/11/14/17 四个时点重新排上。

但要真正生效，得在手机系统里放行（国产 ROM 默认会拦）：

1. 设置 → 应用 → 小满 → 自启动 / 允许后台活动 → 打开
2. 电池 → 应用耗电管理 → 小满 → 允许后台运行 / 不限制
3. 最近任务里把小满下拉锁定（小米、vivo、OPPO 都有这个手势）

还有一条最容易被忽略：**不要点"强行停止"**。强行停止会取消这个 App 的所有闹钟，直到你手动再打开一次。

重启后提醒不响，九成是第 1 条没开，跟代码无关。
